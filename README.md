# 骨質疏鬆症治療指引與健保用藥決策系統 (Osteoporosis Treatment Decision Support System)

這是一套為台灣醫療專業人員設計的「**骨質疏鬆症個人化治療決策互動系統**」。本系統將「中華民國骨質疏鬆症學會 (TOA) 臨床指引」的醫學邏輯與「台灣全民健保藥物給付標準 (條文 9.22)」的繁雜規範進行深度整合，只需輸入病患的基本臨床參數，系統即可**即時動態推導**出最適合的治療藥物排序、健保給付資格，並提供臨床禁忌症的警示。

## 🌟 核心功能特性 (Key Features)

*   **零安裝、離線可用：** 系統被封裝為單一、輕量化的 `.html` 檔案。無需依賴伺服器或資料庫，下載後雙擊即可在任何現代瀏覽器 (Chrome, Edge, Safari) 中流暢運行。
*   **動態風險分級 (Dynamic Risk Stratification)：**
    *   根據 DXA T-Score 與骨折病史，自動將病患歸類為「正常」、「骨量缺乏」、「高骨折風險 (High Risk)」或「極高骨折風險 (Very High Risk)」。
    *   精準支援 2023/2024 最新指引：只要 T-Score $\le -3.0$ 合併多處骨折，或是近 12 個月內有新骨折，系統將自動升級至極高風險。
*   **健保給付自動判定 (NHI Eligibility Checker)：** 內建台灣健保規範邏輯，自動判定病患條件是否符合健保開藥標準，並明確標示「符合健保」或「建議自費」。
*   **V4 動態藥物排序引擎 (Dynamic Drug Sorting Engine)：** 藥物清單不再是靜態文字。系統會根據輸入的參數**即時洗牌**：
    *   `⭐️ 首選`：極高風險時，Romosozumab / Teriparatide 會自動浮現至頂部；腎衰竭 (eGFR < 35) 時，Denosumab 會躍升為第一順位。
    *   `✓ 健保給付`：符合常規健保規範的抗吸收藥物。
    *   `自費/次線`：未達健保標準但臨床可用的選項。
    *   `❌ 臨床禁忌`：當偵測到禁忌症 (如：近期心肌梗塞禁用 Romosozumab、腎功能低下禁用雙磷酸鹽類)，該藥物會立刻被標記為禁忌、反灰並**自動沉降至列表最底層**。
*   **糖尿病骨鬆悖論警示：** 針對第二型糖尿病 (T2DM) 病患，系統會自動跳出警訊，提醒醫師 DXA 數值可能高估骨強度，建議搭配 FRAX (勾選類風濕關節炎作替代) 或 TBS 進行綜合評估。
*   **治療金律與接續策略：** 內建停藥反彈警示 (如 Denosumab 停藥的骨折風險) 與促骨生成劑的接續治療規範。

## 🛠️ 技術架構 (Technology Stack)

本系統採用純前端技術打造，確保最高的相容性與執行速度：

*   **HTML5 & CSS3:** 負責頁面結構與基礎樣式。
*   **Tailwind CSS (via CDN):** 提供現代化、響應式 (Responsive) 且高質感的 UI 設計。
*   **Vanilla JavaScript (ES6+):** 負責核心運算邏輯、事件監聽與 DOM 元素的動態渲染，不依賴龐大的框架 (如 React 或 Vue)，確保檔案極致輕巧。
*   **FontAwesome Icons:** 提供清晰直覺的視覺圖示。

## 🚀 如何使用 (How to Use)

1.  下載本專案中的 `osteoporosis_decision_system_v4.html` 檔案。
2.  使用任何現代網頁瀏覽器 (如 Google Chrome, Microsoft Edge, Safari) 開啟該檔案。
3.  在左側的 **「病患臨床參數輸入」** 區塊，依序設定病患的真實狀況：
    *   選擇生理族群/年齡。
    *   拉動滑桿設定最低 T-Score (介於 0.0 到 -5.0 之間)。
    *   選擇脆弱性骨折病史。
    *   設定腎絲球過濾率 (eGFR) 狀態。
    *   勾選符合的特殊臨床條件與禁忌症 (如：糖尿病、近期心肌梗塞、低血鈣等)。
4.  右側的 **「推薦治療藥物排序與處方策略」** 區塊將會**即時、動態地**更新推薦結果與警示訊息。

## ⚠️ 免責聲明 (Disclaimer)

*   **僅供參考：** 本系統為「臨床決策輔助工具 (Clinical Decision Support Tool)」，旨在協助醫療人員快速檢索指引與健保規範，**絕對不能取代專業醫師的最終臨床判斷**。
*   **實名核對：** 台灣健保給付規定可能隨時更新 (如事前審查規範、專案申請條件)，開立處方前，請務必再次核對衛福部健保署公告之最新「全民健康保險藥品給付規定」。
*   **個別差異：** 病患可能具有系統未涵蓋之罕見共病或用藥過敏史，處方前仍需進行全面的個別化臨床評估。
